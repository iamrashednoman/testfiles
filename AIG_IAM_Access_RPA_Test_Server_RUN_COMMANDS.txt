4.2  ServiceNow
Where: Console, Admin or Developer | Settings › ServiceNow
------------------------------------------------------------------------------

IN THE CONSOLE:
  Poll ServiceNow for tickets:                         Off (On only for the end-to-end test)
  Instance URL:                                        https://<servicenow instance>
  Authentication:                                      basic, oauth_password or oauth_client_credentials, as the ServiceNow team says
  Username:                                            the bot's ServiceNow account
  ServiceNow — bot account password / OAuth client secret: typed here, kept in the Windows credential store of the bot, never shown again
  Match tickets by:                                    assignment_group
  Assignment group (sys_id or name):                   the group of the SailPoint tasks
  Bot account (sys_id, user name or name):             the bot's ServiceNow user
  Accepted application IDs:                            2565 (default)
  Close the ticket when the request failed:            On (default)
  State set on pickup:                                 2 (default)

  3. Preview tickets (uses the saved settings). Nothing is written to ServiceNow.
